## 確認観点と修正

| 観点 | 見つかった問題 | 修正 |
|---|---|---|
| 初めての設定 | 調査と実装開始が混在 | QUICKSTARTで読み取り中心の環境確認、計画確認、最小テストを分離 |
| 必要な道具 | MCPが必須に見える | CLIを基本とし、MCPは必要性を確認して追加 |
| 作業場所 | 指示文と生成レポートの混同、公開場所への記録混入 | HARNESS_REPO／PROJECT_ROOT／私有WORK_ROOTを区別し、レポート先を固定 |
| README | 長文中心で入口と工程が見えにくい | 短い要約、3ステップ、工程図、状態バッジ、資料リンクを追加 |
| 完了判定 | コミットやファイルの存在だけで証拠になりうる | 未コミット入力・出力・評価対象をハッシュと実行識別で対応付ける設計 |
| 並行作業 | Scene以外の競合対象が曖昧 | .meta、Packages、共有材質、インポートを含めて直列化 |
| 音 | 録画・音声取得と試聴評価が混在 | 収録、数値検査、実際の試聴を別の判定項目に分離 |
| 夜間運転 | 中断後の修正回数・予算が曖昧 | 上限を再開時も引き継ぐ。timeout・締切・保存余白を明示 |
| 録画と秘密情報 | 収録範囲が曖昧 | ゲーム画面とゲーム音に限定。マイク・通知・他アプリは対象外 |
| 公開 | ライセンスと私用資料が混在しうる | 独自文書・図のCC BY 4.0、第三者素材除外、公開前の選別を明示 |
